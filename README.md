# World Model 学习记录

记录深度学习与世界模型相关的论文阅读、模型实现和实验分析。每个主题放在独立目录，包含自己的依赖、运行说明和实验结果。

## 项目导航

| 项目 | 内容 | 状态 |
|---|---|---|
| [07 · MAE](07-mae/README.md) | 遮挡重建、冻结编码器的线性分类、遮挡率对比 | 已完成基础实验 |

MAE 实验中，192 维、6 层编码器在不同遮挡率预训练后，线性分类测试准确率分别为 43.93%（75% 遮挡）与 48.23%（50% 遮挡）。这是当前教学实现的单次实验记录，比较条件与局限见项目说明。

## 使用方式

先进入对应子项目，再按其中的 README 安装依赖和运行：

```bash
cd 07-mae
python -m pip install -r requirements.txt
python train.py
```

GPU 环境的 PyTorch 安装方式见子项目说明。数据集由代码下载；本仓库保留图表与指标，不包含模型权重或 Python 环境。

## 后续项目的组织方式

每个新主题建立独立子目录，维护自己的 README 和 requirements.txt，并在上方导航中添加链接。整个仓库统一由根目录的 Git 管理。
